# Breathe ESG Platform

Enterprise ESG emissions review and analytics platform built for the Breathe ESG Internship Assignment.

## Features

- Multi-tenant ESG data architecture
- Django REST API backend
- React + TypeScript frontend
- ESG emissions dashboard
- Dynamic analytics charts
- File upload workflows
- Analyst review queue
- Audit logs
- Approval / rejection workflow
- Scope 1 / Scope 2 / Scope 3 tracking

## Tech Stack

### Frontend

- React
- TypeScript
- Tailwind CSS
- Recharts
- Axios

### Backend

- Django
- Django REST Framework
- SQLite
